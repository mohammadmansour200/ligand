# Credits & Acknowledgments

Ligand exists thanks to the extraordinary dedication of open-source scientists, engineers, and designers. We proudly credit and express our deepest gratitude to the foundational projects, scientific databases, and creative assets that make Ligand possible.

- [RDKit](https://www.rdkit.org) - core cheminformatics operations

- [OPSIN](https://www.ebi.ac.uk/opsin/) - name-to-structure conversion

- [PubChem](https://pubchem.ncbi.nlm.nih.gov/) - structure-to-name conversion

- [Ketcher](https://github.com/epam/ketcher) - sketching toolbar icons

- [Anthony Boyd Graphics](https://anthonyboyd.graphics/mockups/microsoft-surface-pro-x-mockup/) - Surface Pro X mockup frame used in Ligand's website hero image
- [Screenshot.Rocks](https://screenshot.rocks) - mobile mockup frame used in Ligand's website hero image
